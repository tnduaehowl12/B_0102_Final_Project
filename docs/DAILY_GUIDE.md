# SCV 일지 작성 가이드

2026-10-08 · 작성 도윤 (PM)

매일 **21:00 전**에 우리 팀 브랜치(`feature/<팀>`, 예: `feature/vision`)에 **일지 md 하나 + 그림·영상**을 올리면 됩니다. 폴더는 스크립트가 만들어 주고, 여러분은 파일을 넣고 md에 「여기에 이 그림」 자리만 표시하면 돼요. PM이 확인해 노션 「데일리 로그」에 반영합니다.

## 하루 흐름 3단계

저장소 맨 위 폴더(`B_0102_Final_Project`)에서, **우리 팀 브랜치**에 있는지 먼저 확인하고 시작해요 (`git switch feature/<팀>` — 팀 브랜치 이름은 README 의 「브랜치」 표).

1. **만들기** — 할 일이 없어요. 10/16까지의 일지 파일(`docs/daily/<내 GitHub 아이디>/날짜.md`)과 `img/`·`video/` 폴더를 PM이 미리 만들어 두었어요. `git pull` 한 번 하고 **오늘 날짜 파일을 열어** 쓰면 됩니다. 아무것도 안 쓴 파일은 허브가 미제출로 봐요.

   파일이 없는 날(10/10, 10/17 이후)이나 폴더가 안 보일 때만:

   ```bash
   scripts/daily.sh
   ```
2. **쓰기·넣기** — 그림은 `img/`, 영상은 `video/`에 넣고, md를 채우면서 그림·영상이 들어갈 자리에 한 줄씩 표시해요 (아래 「그림·영상 자리 표시」).
3. **올리기** — 크기·토큰 검사 후 일지 폴더만 커밋되고, push는 직접 해요. 허브가 5분 안에 가져가요.

   ```bash
   scripts/daily.sh done
   git push
   ```

   `done` 이 처음에 GitHub 아이디를 물으면 내 일지 폴더 이름과 같은 값을 넣어요. 검사 없이 `git add docs/daily && git commit -m "daily: 날짜" && git push` 로 올려도 됩니다.

## 폴더·파일 위치

내 GitHub 아이디 폴더 하나에 모든 날의 일지가 모입니다. md는 하루에 하나, 파일 이름이 곧 날짜예요.

```text
B_0102_Final_Project/
└── docs/daily/
    └── <내 GitHub 아이디>/
        ├── 2026-10-09.md        ← 오늘 일지 (하루 1개)
        ├── 2026-10-10.md
        ├── img/                 ← 스크린샷·사진·짧은 GIF
        │   └── 2026-10-09_rviz-map.png
        └── video/               ← 짧은 영상
            └── 2026-10-09_dock-test.mp4
```

| 넣을 것 | 경로 | 파일 이름 (권장) | 크기 |
| --- | --- | --- | --- |
| 오늘 일지 | `docs/daily/<아이디>/` | `YYYY-MM-DD.md` (스크립트가 만듦) | — |
| 스크린샷·사진·GIF | `docs/daily/<아이디>/img/` | `날짜_무엇.png` 예: `2026-10-09_rviz-map.png` | 5 MB 이하 (넘으면 노션에 링크로만) |
| 짧은 영상 | `docs/daily/<아이디>/video/` | `날짜_무엇.mp4` 예: `2026-10-09_dock-test.mp4` | 50 MB 미만 (5 MB 넘으면 허브가 줄여서 올림) |
| 긴 영상 (50 MB 이상) | 저장소에 넣지 않음 | YouTube 「일부 공개」 링크를 md에 한 줄 | — |

파일 이름은 영문·숫자·`-`·`_`만 쓰면 편해요. 휴대폰·캡처 도구가 붙인 기본 이름(`Screenshot from 2026-10-09 14-22-31.png`, `20261009_142231.mp4`)도 그대로 써도 돼요 — 이름 속 날짜로 어느 날 파일인지 알아냅니다.

## md에 무엇을 쓰나

md 맨 위 `---` 사이 4줄은 노션 속성 칸으로, 그 아래 제목들은 노션 본문으로 들어가요. 항목마다 짧게, 한 줄에 하나씩 씁니다.

| 항목 | 무엇을 | 예시 |
| --- | --- | --- |
| `date` | 스크립트가 채움 — 손대지 않기 | `2026-10-09` |
| `work` | COOP Hub에 배정된 내 업무 번호 | `T3` |
| `title` | 오늘을 한 줄로 | `rssi_scanner 1 Hz 발행 성공` |
| `blocked` | 막혀서 PM 도움이 필요하면 `true` (허브가 PM에게 바로 알림) | `false` |
| 오늘 한 일 | 한 것을 항목마다 한 줄 | `- iw scan으로 핫스팟 RSSI 읽기 확인` |
| 시행착오 | 안 됐던 것과 어떻게 풀었는지 | `- 스캔 중 로봇 통신 끊김 → 채널 지정으로 해결` |
| 강조하고 싶은 것 / 달성 | 자랑할 결과 + **그림·영상 자리** | 아래 「그림·영상 자리 표시」 |
| 내일 할 일 | 내일 업무 한 줄씩 | `- precise 액션 서버` |
| 막힌 것 | PM 도움이 필요한 것, 없으면 `없음` | `- 없음` |

`<!-- -->`로 감싼 안내 주석은 노션에 안 나가요. 지우지 않고 두어도 됩니다.

## 그림·영상 자리 표시

파일을 `img/`·`video/`에 넣고, md에서 **보여주고 싶은 자리에 아래 줄 하나**만 쓰면 노션에서 그 자리에 나와요. 한 줄에 하나씩, 경로는 `img/` 또는 `video/`부터 씁니다.

| 넣을 것 | md에 쓸 줄 (복사해서 이름만 바꾸기) |
| --- | --- |
| 그림 | `![RViz 지도](img/2026-10-09_rviz-map.png)` |
| 이름에 빈칸이 있는 그림 | `![스캔 결과](<img/Screenshot from 2026-10-09 14-22-31.png>)` — `< >`로 감싸기 |
| 영상 | `video: video/2026-10-09_dock-test.mp4 Dock 10회 시험` |
| 긴 영상 (YouTube) | `video: https://youtu.be/xxxxxxxx 시연 리허설` |

- 대괄호·`video:` 뒤의 글자는 설명이에요. 무엇을 보여주는지 짧게 씁니다.
- **자리를 표시하지 않은 파일도 빠지지 않아요.** 노션 맨 아래 「📷 사진·영상」에 찍은 시각 순으로 붙습니다. 설명이 필요한 것만 자리를 표시하면 돼요.
- 파일 이름이 md에 쓴 것과 한 글자라도 다르면 그 자리에 제대로 붙지 않아요. 복사·붙여넣기를 권해요.

## 완성 예시

`docs/daily/<아이디>/2026-10-09.md`를 이렇게 채우고, `img/`에 `2026-10-09_rssi-log.png`, `video/`에 `2026-10-09_scan-drive.mp4`를 넣은 경우예요.

```markdown
---
date: 2026-10-09
work: T3
title: rssi_scanner 1 Hz 발행 성공
blocked: false
---
## 오늘 한 일
- RPi에서 iw scan으로 핫스팟 RSSI 읽기 확인
- rssi_scanner 노드: /robot4/survey/raw 1 Hz 발행

## 시행착오
- 전체 채널 스캔은 3초 걸림 → 핫스팟 채널만 스캔해서 1초 안쪽으로

## 강조하고 싶은 것 / 달성
- 핫스팟을 끄면 곧바로 미검출(detected=false)로 바뀌는 것 확인
![1 Hz RSSI 로그](img/2026-10-09_rssi-log.png)
video: video/2026-10-09_scan-drive.mp4 주행하며 측정하는 모습

## 내일 할 일
- precise 액션 서버 (정지 30초 중앙값·IQR)

## 막힌 것 (PM 도움 필요)
- 없음
```

예시의 내용(스캔 시간 등)은 형식을 보여주려고 지어낸 것이에요.

## 단위테스트를 통과했을 때

시험을 통과한 날은 「강조하고 싶은 것 / 달성」에 아래 모양으로 적어 주세요. PM이 `✅ 단위테스트 통과:` 표시를 찾아 노션 「단위테스트」 표에 옮겨요. **실패한 시험은 「시행착오」에만** 적어요.

```markdown
## 강조하고 싶은 것 / 달성
- ✅ 단위테스트 통과: rssi_scanner 1 Hz 발행
  - 단계: 1 단위 · IF-02 · 로봇 4번
  - 기준: 1 Hz ± 10 %, 10분 동안 누락 0
  - 결과: 평균 1.01 Hz, 누락 0 / 600
  - 근거: 아래 그림
![10분 발행 로그](img/2026-10-12_raw-hz.png)
```

| 줄 | 쓰는 것 |
| --- | --- |
| `- ✅ 단위테스트 통과:` | 이 글자 그대로 + 시험 이름 (노드 이름 + 무엇을) |
| 단계 | `1 단위` · `2 두 기능` · `3 세 기능 이상` · `4 전체 순찰` 중 하나 · 관련 IF 번호 · 환경 (`mock` · `rosbag` · `로봇 4번` · `로봇 3번`) |
| 기준 | 시험 전에 정한 통과 기준 (숫자로) |
| 결과 | 실제로 나온 값과 횟수 |
| 근거 | 그림·영상은 **블록 바로 아래 줄 맨 앞에** 따로 (위 「그림·영상 자리 표시」 문법), rosbag은 위치만 |

- 시험 하나에 블록 하나. 여러 개를 통과했으면 블록을 여러 개 써요.
- 두 사람 이상이 같이 한 시험은 **한 사람만** 적고, 결과 줄 끝에 `(함께: 이름)`을 붙여요.
- 예시의 숫자는 형식을 보여주려고 지어낸 것이에요.

## 넣으면 안 되는 것 · 자주 묻는 것

### 🚫 넣으면 안 되는 것

레포는 **공개**입니다. 한 번 올라가면 기록이 남으니 올리기 전에 한 번만 확인해 주세요.

| 안 됨 | 대신 이렇게 |
| --- | --- |
| 토큰·비밀번호·IP 주소가 보이는 화면 캡처 | 해당 부분을 잘라내거나 가리고 저장 |
| 사람 얼굴이 나오는 사진·영상 | 얼굴이 안 나오게 다시 찍거나 가리기 |
| 50MB가 넘는 영상 | YouTube **일부 공개**로 올리고 `video: https://youtu.be/… 설명` 한 줄만 적기 |
| 5MB가 넘는 이미지 | 줄여서 넣기 (5MB가 넘으면 노션에 그림이 아니라 GitHub 링크로만 들어가요) |
| md 본문에 토큰처럼 생긴 문자열 | `done`이 커밋을 거부해요. 지우고 다시 실행 |

### ❓ 자주 묻는 것

| 이럴 때 | 이렇게 |
| --- | --- |
| 자정이 지나서 어제 일지를 마무리할 때 | `scripts/daily.sh done 2026-10-08` 처럼 날짜를 붙여 실행 |
| 막혀서 PM 도움이 필요할 때 | frontmatter의 `blocked: true` → 허브가 PM에게 바로 알려요 |
| GitHub 아이디를 잘못 넣었을 때 | `scripts/daily.sh id <GitHub아이디>` |
| AI·CLI에게 대신 실행시킬 때 | 확인 질문을 건너뛰도록 `--yes`를 붙여요 |
| main 브랜치에서 실행했다고 경고가 뜰 때 | `git switch feature/<팀>` 으로 우리 팀 브랜치로 옮긴 뒤 다시 실행 |
| 노션에서 오타를 발견했을 때 | 노션에서 고치지 말고 **md를 고쳐서 다시 커밋** (다시 반영되면 노션 수정분은 덮어써져요) |
| 사진을 넣었는데 본문에 자리를 안 잡았을 때 | 괜찮아요. 일지 맨 아래 「📷 사진·영상」에 시간순으로 붙어요 |
| 마감은 언제? | 매일 **21:00**. 그 전에 허브가 한 번 알려줘요 |
| 일지만 커밋하면 PM 확인을 기다려야 하나요? | 아니요. 일지만 바뀐 커밋은 확인 대기가 생기지 않아요 |

> 💡 헷갈리면 순서만 기억하세요: **`daily.sh` → 파일은 `img/`·`video/`에 → md에 자리 표시 → `daily.sh done` → `git push`**
