## 시행착오
- 팀 브랜치에 그 팀 패키지만 남겼더니 `scv_msgs` 가 바뀔 때마다 브랜치마다 따로 맞춰야 했고 다른 팀 코드를 볼 수 없었음 → 같은 날 모든 팀 브랜치를 main 과 같은 구조(패키지 전체)로 되돌림
- 워크스페이스 폴더 이름을 `ros2_src` 로 만들었다가 관례에 맞춰 `ros2_ws` 로 변경
- 일지 가이드에 `git config pull.rebase` 설정 안내를 넣었다가, 팀원이 따로 할 일을 만들지 않으려고 뺌. 팀원은 `git pull` 만 하면 되도록 유지
- 미검출을 RSSI −100 으로 적는 방식은 실제 약한 신호와 구분되지 않음 → RSSI 팀과 상의해 `detected` 필드로 분리
