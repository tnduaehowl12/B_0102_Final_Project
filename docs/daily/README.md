# 일지 (docs/daily)

하루를 마칠 때 **내 브랜치**에 오늘 일지를 커밋한다. COOP Hub가 읽어서 제출 현황을 보여 주고,
PM이 확인한 뒤 「노션 반영」을 누르면 노션 데이터베이스 「데일리 로그」에 사람마다 한 행으로 들어간다.

```
docs/daily/<내 GitHub 아이디>/
├── 2026-10-08.md      ← 하루 1개, 파일 이름 = 날짜
├── img/               ← 스크린샷·사진·짧은 GIF
└── video/             ← 짧은 영상 (5 MB 넘으면 허브가 줄여서 노션에 올림)
```

## 매일

```bash
scripts/daily.sh          # 오늘 md와 img/, video/가 없으면 만든다 (처음 한 번은 GitHub 아이디를 묻는다)
# … 내용 채우기, 그림은 img/, 영상은 video/ …
scripts/daily.sh done     # 크기 검사 + 일지 폴더만 커밋 (push는 직접: git push)
scripts/daily.sh done 2026-10-07   # 자정 넘어 어제 일지를 올릴 때
scripts/daily.sh done --yes        # 묻지 않고 진행 (AI가 대신 돌릴 때. main 브랜치 경고도 넘어감)
```

AI(Claude Code 등)가 대신 돌릴 때는 아이디를 먼저 정해 둔다: `scripts/daily.sh id <GitHub아이디>`.
터미널이 아닌 곳에서 돌면 스크립트는 묻지 않고, 물어야 할 일이 있으면 이유를 말하고 멈춘다.

마감 시각(허브 관리 화면에서 정함, 기본 21:00)까지 아직 없으면 허브가 알림을 보낸다.

## PM이 미리 만든 양식 (v1.15)

PM이 며칠 치 일지 파일을 미리 만들어 둘 수 있다 (`date:`와 `work:`만 채운 양식 + `img/.keep`, `video/.keep`).

```bash
# PM: 아이디 = 허브 관리 → GitHub 연동 표의 「GitHub 아이디」, =T번호는 그 사람의 work:
scripts/daily_prefill.sh 2026-10-11 2026-10-16 dongjun-lee=T4 jaemin=T4 --team 비전            # 만들기만 (커밋 안 함)
scripts/daily_prefill.sh 2026-10-11 2026-10-16 hyunjun=T5 --branch feature/drive --commit     # 그 브랜치에서 만들고 커밋
```
- 이미 있는 파일은 **절대 덮어쓰지 않는다**. 만든 파일만 출력하고, `--commit`이 없으면 커밋하지 않는다 (push는 직접).
- 옵션: `--work T5`(=T번호가 없는 사람의 기본값), `--weekdays`(토·일 건너뜀), `--branch <이름>`(그 브랜치로 바꾼 뒤 만듦, 커밋 안 된 변경이 있으면 멈춤), `--team <이름>`(출력·커밋 메시지 이름표).
- **팀원**: `git pull` 한 뒤 평소처럼 `scripts/daily.sh` → 그 파일을 그대로 이어 쓴다. 아직 pull 안 했으면 새로 만들지 않고 "git pull 먼저"라고 알려 준다 (같은 파일을 따로 만들어 pull이 막히는 일을 막음). `img/.keep`이 있으면 `.gitkeep`을 따로 만들지 않는다.
- **양식 그대로면 제출이 아니다**: `date:`·`work:` 말고 아무것도 안 바꾼 파일은 허브 일지 화면에 「양식만 있음」(미제출)으로 보이고, 21:00 알림도 가고, 노션에 반영되지 않는다. `scripts/daily.sh done`도 "아직 양식 그대로예요"라고 하고 멈춘다. 제목(`title:`) 한 줄만 바꿔도 쓴 것으로 본다. 줄바꿈(CRLF)·줄 끝 공백·빈 줄 차이는 상관없다.

## 규칙

- `docs/daily/` 안만 바꾼 커밋은 **컨펌 대기를 만들지 않는다**. 코드와 일지는 따로 커밋해도, 같이 커밋해도 된다
  (같이 커밋하면 코드 쪽 기준으로 컨펌 대기가 된다).
- 그림·영상 순서: md에 쓴 것(`![설명](img/…)`, `video: video/… 설명`)은 **쓴 자리**에,
  파일 이름에 빈칸이 있으면 `![설명](<img/Screenshot from 2026-10-08 14-22-31.png>)`처럼 `< >`로 감싼다.
  md에 안 쓴 `img/`, `video/` 파일은 노션 맨 아래 「📷 사진·영상」에 **찍은 시각 순**으로 붙는다.
  어느 날의 파일인지는 파일 이름 속 날짜(`Screenshot from 2026-10-08 …`, `20261008_142231.mp4`)로,
  이름에 날짜가 없으면 처음 커밋한 날로 정한다.
- 노션에 직접 올라가는 파일은 5 MB 이하(무료 노션 한도). **영상**이 더 크면 허브가 한도 안으로 줄여서(H.264, 해상도·fps 낮춤) 올리고,
  저장소의 원본은 그대로 둔다(허브에 ffmpeg가 없으면 GitHub 링크로). **그림**이 더 크면 GitHub 링크로만 들어가니 줄여서 넣는다.
  **50 MB가 넘는 파일은 저장소에 넣지 않는다** (GitHub 100 MB 거부, 저장소가 무거워져 모두의 clone이 느려진다).
  긴 영상은 YouTube(일부 공개)에 올리고 `video: https://youtu.be/… 설명` 한 줄로.
- 이 저장소는 **공개**다. 토큰·IP·비밀번호가 보이는 화면, 사람 얼굴이 나오는 사진·영상은 넣지 않는다.
- 노션은 허브만 쓴다. 노션에서 고친 내용은 그 일지를 다시 반영할 때 사라진다 — 고칠 것은 md를 고쳐서 다시 커밋한다.
