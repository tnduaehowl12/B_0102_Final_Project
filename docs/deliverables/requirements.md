# SCV 비즈니스 요구사항 (제출용 초안 v0.1)

> 원본은 노션 「SCV 설계」 — 제출 직전에 다시 뽑는다.

2026-10-10 · 작성 도윤 (PM) · 출처: 팀 노션 「SCV 설계」 8장 (10/10 기준). 번호는 노션과 같습니다.

## 1. 목표

산업 자동화 시설의 **물리 인프라(소방·안전·고정 설비)와 통신 인프라(AMR 운행 경로의 Wi-Fi)를 같은 순찰에서 사람 없이 반복 점검**해 위치 기반 기록과 지도로 유지하고, 이상 후보는 재검증해 확정한다. 법정 점검 사이의 설비 점검 공백을 메우고, 무선 끊김으로 인한 자동화 설비 정지를 미리 막을 근거를 준다. 전문 RF 설계·법정 점검을 대체하지 않고 그 사이를 보완한다.

- 이름: SCV (Smart Check Vehicle). 대상: 산업 자동화 시설(대표: 스마트 물류창고). 검증: 강의장 축소 테스트베드.

| 비범위 | RF 정밀 진단 · 무선망 교체·AP 시공 · 재고 관리·WMS 연동 · 화재 감지·진압 · 실제 산업 인증 수준 판정 · 고정 웹캠 CCTV (10/10 제외) |

## 4. 기술·운영 요구사항 (BR-T)

| ID | 요구사항 | 측정 목표 |
| --- | --- | --- |
| BR-T01 | 측정 커버리지 | 등록 구역 100 % 를 측정 간격 2 m 이하로 (시연: 두 대 1회전 10분 이내) |
| BR-T02 | 위치 기반 측정 품질 | RSSI 1 Hz 이상, 저장 지도 좌표와 같은 시각으로 기록 · 회차마다 같은 경로·높이·속도 |
| BR-T03 | 무선 측정 지표 | 스캔으로 대상 AP(핫스팟) RSSI 만 기록 · 재검증 정지 측정은 30초 RSSI 중앙값·IQR |
| BR-T04 | 지도·신뢰도·보고 | 칸별 평균·중앙값·분산·표본 수 · 표본 부족 칸 '신뢰 낮음' · −72 dBm 미만 음영 100 % 표시 · 순찰 종료 후 보고서 |
| BR-T05 | 기준선 대비 변화 | 여러 회차의 정상 분포에서 벗어난 칸 자동 표시 |
| BR-T06 | 이상 후보 재검증 | RSSI 저하·기준선 이탈·설비 미검출은 '후보'로만 등록 → 재방문 정밀 측정·근접 재촬영 후 최종 판정 · **재검증 없이 '이상' 확정 0건** |
| BR-T07 | 음영 회피 | 기준 미달 칸을 회피 구역으로 표시해 경로에서 제외(표시 후 5초 이내 재계획) · 경계 칸까지 측정 · 측정값 유실 0건 |
| BR-T08 | 협업·병합·인계 | 두 대 측정값을 한 지도로 병합 · 한 대 이탈 후 60초 이내 남은 작업 재배정, 누락 0 |
| BR-T09 | 무인 운용 | Undock 부터 Dock 까지 사람 개입 없는 순찰 완료율 ≥ 95 % |
| BR-T10 | 사람 우선 | 사람·지게차(모형) 이격 ≥ 30 cm, 막힘 시 10초 이내 우회 또는 건너뛰기 |
| BR-T11 | 알림·통합 관제 | 후보·확정 이상·회피 구역 5초 이내 관제 표시 · 로봇·설비·네트워크·작업을 한 지도에서 |
| BR-T12 | [물리] 소화기 유무·위치 | 등록 위치 대비 있음/없음/위치 이상 판정 정확도 ≥ 95 % (20회) |
| BR-T13 | [물리] 압력계 판정 | 정면으로 판별된 영상의 녹색/이상 판정 정확도 ≥ 90 % · 정면 아니면 판정하지 않음 |
| BR-T14 | [물리] 셔터 하강구간 | 하강 띠 위 물체(높이 10 cm 이상) 검출 recall ≥ 95 %, 오경보 ≤ 5 % |
| BR-T15 | [물리] 유도등 점등 | 점등/소등 판정 정확도 ≥ 95 % |

## 5. 비즈니스 규칙 (BR-R)

| ID | 규칙 · 제약 |
| --- | --- |
| BR-R01 | SCV 는 측정·점검·기록까지만 한다. 조치는 담당자가 하고, 로봇은 다음 순찰에서 결과를 다시 확인한다 |
| BR-R02 | 후보·미확인·보간값은 확정값이나 정상으로 처리하지 않는다 |
| BR-R03 | 사람과 지게차가 항상 먼저다 |
| BR-R04 | 측정 구역·설비 등록·기준·순찰 일정은 관리자만 바꾼다 |
| BR-R05 | 영상은 점검 목적으로만, 얼굴 저장 최소화 · 측정 데이터는 시설 내부에만 |
| BR-R06 | 전문 RF 설계·법정 점검을 대체하지 않는 보조 모니터링으로 운영한다 |
| BR-R07 | 축소 테스트베드 결과를 실제 창고 재현이라 주장하지 않는다 · 휴대폰 핫스팟으로 만든 음영을 실제 설비 AP 음영과 같다고 주장하지 않는다 |

## 7. 성과 지표 · 유스케이스

| 지표 | 도입 전 | 목표 |
| --- | --- | --- |
| 네트워크 지도 갱신 주기 | 문제가 생기면 외주 측정 | 주 1회 이상 (순찰마다) |
| 음영 문제를 아는 시점 | 로봇·단말이 멈춘 뒤 | 순찰 측정 시 (장애 전) |
| 측정 조건 일관성 | 측정자마다 다름 | 같은 경로·높이·속도 |
| 1회 측정으로 확정한 이상 | 오탐 구분 없음 | 0건 (모두 재검증 후 확정) |
| [물리] 소방 설비 확인 빈도 | 연 1–2회 + 수시 | 매일 (순찰 1회 이상) |

- UC-01 정기 순찰: 관제에서 시작 → 작업 배정 → 이동하며 네트워크 측정 → 병합 지도
- UC-02 이상 후보 재검증: 1차 후보 → 다른 로봇 재방문 정지 측정 → 확정/해제/미확인
- UC-03 배치 변경 후 재측정 → 기준선 대비 변화 구역
- UC-04 순찰 보고서: 음영·커버리지 저하 의심 구역 → IT 담당 확인
- UC-05 로봇 이탈 → 남은 작업 인계 · 관제에서 재배정·비상정지
- UC-06 [물리] 소화기 미검출 → 재확인 → 확정 / 압력 이상 알림
- UC-07 [물리] 셔터 적치·유도등 소등 → 알림 → 다음 순찰 해소 확인
- UC-08 [통신] 핫스팟을 끄면 그 구역이 회피 구역으로 바뀌고 경로 재계획 → 다시 켜면 경계 재측정으로 해제

인수 기준: 검증 시나리오에서 팀이 고른 핵심 BR-C·BR-T 목표를 모두 충족하고, 해결되지 않은 안전 문제가 없을 때 인수한다. 시험과의 대응은 `docs/TEST_PLAN.md`.
