# SCV Critical Path Items (초안 v0.1)

2026-10-10 · 작성 도윤 (PM) · 강의 Day 5 「Critical Path Items」 형식. **팀 검토 전 초안입니다.**

일정에 직접 영향을 주는 작업, 곧 늦어지면 최종 완성(10/14 수)이 그만큼 늦어지는 작업만 모았습니다. 매일 18:00 에 현황과 퍼센트를 고치고 다음 날 9:30 에 공유합니다. 「남은 날짜」는 10/10 기준입니다. 스프레드시트용 사본은 `docs/deliverables/critical_path_items.csv`.

## 가장 긴 의존 구간

```text
지도 고정 → 위치 추정·통로 주행 → mission_executor → 팀 사이 묶음 시험 → 로봇 한 대 순찰 → 로봇 두 대와 예외 → 시연
  10/10          10/12              10/13            10/13              10/13            10/14         10/14
```

주행(1명)이 이 구간의 대부분을 차지합니다. 비전·RSSI·관제는 10/13 묶음 시험에서 주행과 만나므로, 각 팀의 「묶음 시험 전제」 항목이 10/13 까지 나와야 합니다.
